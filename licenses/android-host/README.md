## Intentional changes and exclusions

- `AndroidManifest.xml` references Nexus's existing launcher artwork instead of
  template artwork. The new `nexus_launcher.png` is byte-for-byte the committed
  Nexus master icon, whose source design is `scripts/gen-icons.py`.
- The generated `.gitignore` additionally excludes the binary wrapper JAR.
- No template PNGs or robot vectors were imported; their independent artwork
  authorship/attribution was not established by inspecting the text headers.
- The unused Hello World layout was not imported. The real TauriActivity owns
  the WebView; there is no replacement placeholder application screen.
- The host README, this review and root ignore exceptions are original project
  integration documentation, not upstream code.
- No Gradle distribution, wrapper JAR, plugin native code, signing material,
  machine path or compiled foreign library is vendored here. Binary dependency
  license/notice delivery remains a separate prerequisite before an APK ships.

Further original Nexus integration adds the app-scoped folder browser, MainActivity
JNI/lifecycle entry points, localized folder-dialog resources, and precise ProGuard
method keeps. It also pins the official Gradle 8.14.3 distribution checksum. These
are intentional changes from the baseline report, not unmodified upstream files.
The test-only JUnit/Robolectric harness is not distributed as the application.

The original NexusWindowInsets controller and its Activity lifecycle integration
apply Android system-bar, cutout and keyboard insets to the existing native content
parent. No upstream source was imported for this controller. Its framework-modeled
tests and actual-source mutation control are not physical-device layout evidence.

The original native NexusLaunchActivity preflight asks for local receive-audio
permission only before the station host is entered. MainActivity is now app-private;
its original Tauri identity and engine remain intact. Permission denial is not an
audio implementation or a grant. The seven framework-modeled tests never replace
or execute TauriActivity. These additions import no upstream implementation.

The original NexusFt4222Usb class uses Android's USB Host API to claim only an
already-authorized, named FT4222 interface A without force-detaching a driver.
It performs bounded concurrent full-duplex bulk I/O, preserving actual raw
transfer boundaries, and ends chip select with a zero-length OUT. It imports
no upstream implementation or new dependency. Its test-only syscall shadow
is original Nexus code; existing Robolectric remains the same dependency.
Descriptor fixture serialization was checked against the public Android 15
UsbDevice/UsbInterface/UsbConfiguration/UsbEndpoint parcel contracts, not
copied from an implementation. This source is not yet connected to the Rust
WaterfallSource, and it does not add a USB permission prompt or claim hardware
acceptance. No D2XX/LibFT4222 binary or third-party USB driver is included.

The original Rust Android FT4222 adapter now captures application/class JNI
references and calls the original USB Host transport on the scope worker.
It uses JNI already re-exported by the locked Tauri/Tao stack; no additional
package, upstream implementation or native binary is introduced. ProGuard
keeps match these real JNI entry points. USB grant UI and hardware proof
remain separate requirements.

The original NexusUsbLaunchActivity is an app-private, single-instance native
USB permission preflight. It uses Android USB Host and existing framework APIs,
not a vendor driver or a replacement station. The immutable package-scoped
permission intent is not authority; selection rechecks the current OS grant.
No upstream source/dependency is imported by its code, EN/zh strings, modeled
tests or shared descriptor fixtures. Physical Android and station acceptance
remain outstanding.
