## Intentional changes and exclusions

- `AndroidManifest.xml` references Nexus's existing launcher artwork instead of
  template artwork. The new `nexus_launcher.png` is byte-for-byte the committed
  Nexus master icon, whose source design is `scripts/gen-icons.py`.
- The generated `.gitignore` additionally excludes the binary wrapper JAR.
- No template PNGs or robot vectors were imported; their independent artwork
  authorship/attribution was not established by inspecting the text headers.
- The unused Hello World layout was not imported. The real TauriActivity owns
  the WebView; there is no replacement placeholder application screen.
- The host README, this review and root ignore exceptions are original project
  integration documentation, not upstream code.
- No Gradle distribution, wrapper JAR, plugin native code, signing material,
  machine path or compiled foreign library is vendored here. Binary dependency
  license/notice delivery remains a separate prerequisite before an APK ships.

Further original Nexus integration adds the app-scoped folder browser, MainActivity
JNI/lifecycle entry points, localized folder-dialog resources, and precise ProGuard
method keeps. It also pins the official Gradle 8.14.3 distribution checksum. These
are intentional changes from the baseline report, not unmodified upstream files.
The test-only JUnit/Robolectric harness is not distributed as the application.

The original NexusWindowInsets controller and its Activity lifecycle integration
apply Android system-bar, cutout and keyboard insets to the existing native content
parent. No upstream source was imported for this controller. Its framework-modeled
tests and actual-source mutation control are not physical-device layout evidence.
